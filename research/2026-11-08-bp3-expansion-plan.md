## 1. 为什么现在做 BP3 扩展（三条实测证据）

### 1.1 需求曲线平坦，不存在"玩到 L53 就流失"

英文 BP3 关卡页 28d 曝光（GSC page 维度，实测）：

| 段 | 平均曝光/关 | 段内峰值 |
|---|---|---|
| L1-10 | 1,973 | L6: 5,017 |
| L11-20 | 2,017 | L16: 4,901 / L17: 4,877 |
| L21-30 | 1,473 | L21: 3,846 |
| L31-40 | 2,037 | L33: 6,098 |
| **L41-53** | **1,258** | L45: 3,256 / L50: 1,823 |
| **L137（孤立单关）** | **200** | 13 点击 |

**L41-53 与 L1-10 只差 36%，没有衰减趋势。** 更关键：L137 是孤立存在的一关（前后都没页），单靠自己也拿到 200 曝光 / 13 点击。

→ **需求一直存在到 L137+，缺口纯粹是"我们没页"。**

### 1.2 「L54-136 零信号」是 GSC 盲区，不是没需求

GSC 只返回**我们已有排名**的词。没页 → 没排名 → 没曝光 → 看起来"零信号"。

反证：`brain puzzle 3 level 30 / 50 / 137` 这三个**有页且实际在拿流量**的词，在 keyword_volume 里**全部 null**（Google Ads 口径对 <10/月 不显示）。所以这个工具也不能用来判断关卡需求。

**唯一可用判据 = 邻近关卡的需求曲线。** 曲线平坦即成立。

### 1.3 trickystory 已经进场

- 它 11-06 新建 `brain-puzzle-3-crazy-mind-solutions` + `brain-puzzle-3-crazy-mind-halloween-answers`（2 页）
- 它的打法固定为「100 关/页」（见 block-out: `level-1101-to-1200`、loop-sort: `level-101-to-200`）
- 按此推演：它覆盖 L54-137 只需 1 页，**不可能比我们细**

→ 粒度优势在我们这边，但**前提是我们先铺**。它一旦占住 SERP，我们再补就是追赶。

## 3. BP3 扩展的执行要求（交给 gridpaw）

1. **粒度不变**：1 关 = 1 页，沿用现有 gen 管线，不合并、不写"100 关一页"
2. **顺序**：L54 → L137 顺序铺，不跳；先英后德
3. **每页必须包含**：题面（关卡谜题原文）、解法步骤、截图位、FAQ
4. **发布节奏**：建议 10-15 页/天，8 天内铺完 83 关（避免一次性 83 页触发 thin content 风险）
5. **验收**：铺完后 14 天看 GSC —— 新增页若平均曝光 < 300/关，说明该段需求判断有误，停手复查

**红线**：不得为凑数写空页；不得复制其他站内容；不得改已有 L1-53 页的 URL。

## 4. 本轮已立住的判据（防止重复试错）

### 4.1 「找下一个 BP3」的三条件（缺一不可）

1. **需求存在** —— 用「竞品同游戏每页 etv > 1」或「邻近词曲线平坦」验证
2. **供给有空窗** —— SERP 网页位强竞品（DR≥30）≤ 2 个，且竞品粒度为「100 关/页」
3. **盘子够大** —— 月下载 ≥ 500 万

### 4.2 三个免费发现源已实测证伪

| 源 | 实测 | 结论 |
|---|---|---|
| GSC 扫全量 query | 4,826 词 → 151 攻略形态 → 他游仅 3 个（曝光 5-27） | ❌ 只是我们的记分板 |
| 新词服务（334 批/42 天） | 20 个攻略形态词 → 全 volume 0 | ❌ 攻略新词不上热榜 |
| keyword_volume | 连在拿流量的 `level 30/50/137` 都 null | ❌ 关卡词低于阈值 |

**唯一有效的发现路径**：竞品出词（site_keywords，8 积分/站，算 etv/页）+ GrokBot 卡关信号（X）。
