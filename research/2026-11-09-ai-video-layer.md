# sousaku 路数与「普通人能做的 AI 视频站」（2026-11-09）

> 数据：income 完整快照 2026-11-05（9,089 站 / checkout in 1.30 亿）+ domain_overview（sousaku.ai、higgscheap.ai，4 积分）
> **重要**：11-08 与 11-09 的 28d 快照不完整（99 页 / 127 页，完整应 181 页），本报告改用 11-05 完整快照；上一份 checkout 报告据此低估，见文末「数据缺陷」

## 一、先纠正：sousaku 不是游戏攻略站

sousaku.ai 是**日本 AI 创作聚合平台**（图片 / 视频 / 漫画 / 音乐 / 角色 / Agent / API），2025-08-29 注册，订阅制（Unlimited Pass）+ 按量 credits。

| 指标 | 读数 |
|---|---|
| 月访问（2026-09） | 150,293，环比 +33.2% |
| DR | 17 |
| 域龄 | 1.2 年 |
| 流量来源 | **direct 71.5% / referral 14.1% / search 8.8% / social 5.1%** |
| 地域 | **日本 91.5%** |
| 行为 | 10.1 页/访问、停留 697 秒 |
| 排名词 | sousakuai 1,880、sousaku ai 1,670、hotgen v5 330、**sousaku ai nsfw 310** |

**它几乎不靠 SEO。** 91.5% 日本用户、direct 七成——这是产品 + 社群 + 口碑驱动的站，不是内容站。

## 二、我前面分析的确实是 sousaku 的路数

apimart.ai / sousaku.ai / higgscheap.ai 是同一个商业逻辑的三个变体：

| 站 | 模式 | checkout 28d | 月访问 | 模型自研 |
|---|---|---:|---:|---|
| sousaku.ai | C 端创作平台（日区） | — | 150,293 | 无，聚合 |
| apimart.ai | API 聚合转售（西语区） | 54,975 | 360,299 | 无，转售 |
| higgscheap.ai | 多模型按次付费（英文区） | 3,210 | 无数据（0.1 年） | 无，纯前端壳 |

**共同点：不训模型，聚合上游（OpenRouter / Replicate / fal / 各家官方 API），包成前端卖 credits 或订阅。** 技术门槛确实低——higgscheap 注册 0.1 年、DR 0 就已经有 3,210 checkout/28d。

## 三、AI 视频/创作赛道的完整分层（完整快照 11-05）

| 层 | 样本 | 28d checkout | 普通人可做？ |
|---|---|---:|---|
| **原厂模型** | elevenlabs 219.8 万、suno 99.0 万、kling 47.0 万、fal 47.0 万、runway 30.0 万、midjourney 18.3 万 | 18 万–220 万 | 否（要模型/算力/融资） |

| **中转/换皮（普通人层）** | apimart 5.5 万、ai33.pro 2.8 万、chantan.studio 2.16 万、joybox.studio 1.67 万、ainative.studio 9,634、imastudio 8,877、higgscheap 3,210 | **3 千–5.5 万** | **是（技术门槛低）** |

**答案：普通人能做的 AI 视频站是第三层——中转/换皮/聚合，checkout 量级 3 千到 5.5 万/28d。** 新站起量很快：chantan.studio（2026-10 首现）一个月做到 2.16 万，joybox.studio（2026-06）1.67 万，ainative.studio（2026-09）9,634。

## 四、但这条路有个致命前提：获客不靠 SEO

| 站 | search 占比 | direct 占比 | 获客方式 |
|---|---:|---:|---|
| sousaku.ai | 8.8% | 71.5% | 产品 + 社群 +  referral |
| apimart.ai | 17.2% | 60.2% | 品牌 + 口碑 + 8.7% 付费投放 |
| zenfy.ac | 0.8% | 6.4% | **85% 付费投放** |
| hosted 池 AI 视频词 | 几乎没有搜索量 | — | — |

**这一类生意的门槛不在技术，在获客和运营**：上游额度采购、支付风控（AI 类拒付率高）、价格战（higgscheap 主打「比官方便宜 3 倍」）、客服、模型版本跟进。

**这不是 SEO 能力能打的仗。** 用户现有能力（内容站 + SEO + 静态站）在这一层用不上，等于重新学一门生意。

## 五、如果一定要做，三个诚实的选项

| 选项 | 做什么 | 门槛 | 与现有能力重合 |
|---|---|---|---|
| A | 中转站（higgscheap 模式）：接 2-3 家上游，按次卖 credits | 支付/风控/额度/客服 | 低 |
| B | API 聚合（apimart 模式）：面向开发者卖额度，抢 OpenRouter 品牌词 | 上游商务、稳定性、合规 | 中（有 API 使用经验） |
| C | 内容侧（评测/教程/prompt 库）→ affiliate | 纯 SEO | 高，**但数据显示搜索侧几乎没有量** |

**我的判断：A/B 是运营生意不是建站生意，C 的搜索需求已被平台自己吃掉（用户直接搜品牌名去官网）。三条都不理想，但如果要做，B 的路数已被中国团队跑通（apimart 1.1 年 DR 65 / 36 万访问），比 A 的可复制性强。**

## 六、数据缺陷（必须记录）

`data/income/` 的 28d 快照，**服务端对最近 1-3 天的日期返回的分页数据本身不完整**：

| 日期 | sites | in 总量 | total_pages |
|---|---:|---:|---:|
| 11-01 | 9,024 | 1.304 亿 | 181 |
| 11-02 | 9,026 | 1.300 亿 | 181 |
| 11-03 | 8,076 | 1.276 亿 | 162 |
| **11-04** | **9,074** | **1.300 亿** | **182** |
| **11-05** | **9,089** | **1.300 亿** | **182** |
| 11-06 | 7,172 | 1.260 亿 | 144 |
| 11-07 | 7,930 | 1.285 亿 | 159 |
| **11-08** | **4,945** | **0.354 亿** | **99** |
| **11-09** | **6,349** | **0.968 亿** | **127** |

实测证据：对 `28d=2026-11-09` 直接请求 page 127 返回 49 条且 `has_more=false`，page 128-181 全空——**服务端就是只给 127 页**，不是客户端截断。同一天份 11-05 有 182 页。

**影响**：任何基于 11-08 / 11-09 快照的品类统计都会漏掉 20-30% 的站（例如 higgsfield.ai 188 万、elevenlabs 234 万在 11-09 快照里完全缺失）。上一份 checkout 报告用的就是 11-09 快照。

**已处理**：
1. `fetch_income_month()` 改为按 `has_more` 顺序翻页 + 空页重试 + 末页容量校验（`(pages-1)×50+1 ≤ sites ≤ pages×50`），不通过直接抛错不写盘。
2. 分析口径改为「**挑页数最多、in 总量最高的快照**」（当前是 11-05），不再默认用最新日期。
3. `audit` 的翻页对账仍值得补一条「与同月其他日期比页数，偏离 >20% 告警」，因为单份自校验查不出服务端少给页。

## 七、口径

1. checkout 流量是估算值，不是营收；sousaku 的 15 万月访问与 checkout 数据不可直接换算（它没出现在 income 的 AI 类前 40，说明其支付通道可能不在采集范围）。
2. higgscheap.ai 域龄 0.1 年、DR 0、无流量数据，但已有 3,210 checkout/28d——只能说明「有成交」，不能推断营收。
3. 「普通人层」的 3 千–5.5 万量级来自 7 个样本，非全量统计。
4. sparkline/趋势判断用的是 2026-07~09 三个月。
