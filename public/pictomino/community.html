❓ Questions About Pictomino

Where can I play Pictomino?

The official home is gridpaw.com/pictomino. It runs entirely in the browser — phones, tablets and desktops all work, nothing to install. That is the only place we publish the game, so any other domain offering "Pictomino" is not ours.

Is there an iOS or Android app?

No. Pictomino is a browser game: no app store listing, no download, no account. Open the page and start puzzling. If you see an app claiming to be Pictomino, it is not ours.

Does it cost anything or need an account?

It is free to play and needs no sign-up. You get 5 lives per level, and the whole game — beginner through super-hard — is open without a paywall.

How do I report a bug or suggest a puzzle?

Open an issue on GitHub, or send a message on X. Screenshots of the puzzle that broke help more than a description alone — every Pictomino board is generated from a picture, so the image tells us which one failed.

Can teachers and parents use it in class?

Yes, and no licence or sign-up is involved. Pictomino is designed for kids aged 6 and up: younger children start on the beginner boards, older kids and adults get the hard and super-hard ones. Because every level is a single screen that opens in the browser, a teacher can put it on a projector or hand out tablets without installing anything, and a parent can play the same board alongside the child — each wrong placement costs one of the 5 lives, which makes reasoning before tapping the whole point of the exercise.

Where is the daily puzzle?

The daily board lives at gridpaw.com/pictomino/daily-puzzle. It is the same free game as the main page, just a fresh picture to work through, so there is nothing extra to install or sign up for in order to play it.
